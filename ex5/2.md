# Problem 5.2: Convergence Behavior for $f_4(x) = \sin(\pi x)$

**Problem Statement:**  
Explain the convergence behavior in Exercise 5.1 for the integrand $f_4(x) = \sin(\pi x)$ on $[a, b] = [-1, 1]$.  
You may use Euler's formula $e^{\mathbf{i}z} = \cos z + \mathbf{i}\sin z$ in the form:
$$\sin z = \frac{1}{2\mathbf{i}}\left(e^{\mathbf{i}z} - e^{-\mathbf{i}z}\right)$$
and the geometric series formula:
$$\sum_{j=0}^{N-1} q^j = \frac{q^N - 1}{q - 1}, \quad q \neq 1.$$
*Hint:* What is the exact value of the integral?

---

## 1. Exact Value of the Integral

The function $f_4(x) = \sin(\pi x)$ is odd on the symmetric interval $[-1, 1]$:
$$I = \int_{-1}^{1} \sin(\pi x)\,dx = \left[ -\frac{\cos(\pi x)}{\pi} \right]_{-1}^{1} = -\frac{\cos(\pi) - \cos(-\pi)}{\pi} = -\frac{-1 - (-1)}{\pi} = 0.$$

---

## 2. Composite Trapezoidal Rule Evaluation

For a subdivision of $[a, b] = [-1, 1]$ into $N$ subintervals of length $h = \frac{b - a}{N} = \frac{2}{N}$, the knots are:
$$x_j = -1 + j h = -1 + \frac{2j}{N}, \quad j = 0, 1, \dots, N.$$

The composite trapezoidal rule is defined as:
$$T(h) = h \left[ \frac{1}{2}f_4(x_0) + \sum_{j=1}^{N-1} f_4(x_j) + \frac{1}{2}f_4(x_N) \right].$$

Evaluating at the endpoints $x_0 = -1$ and $x_N = 1$:
$$f_4(x_0) = \sin(-\pi) = 0, \quad f_4(x_N) = \sin(\pi) = 0.$$

Since both boundary terms vanish, the sum can be written without boundary weights:
$$T(h) = h \sum_{j=0}^{N-1} \sin(\pi x_j).$$

---

## 3. Applying Euler's Formula and Geometric Sums

Using the knot definition $\pi x_j = -\pi + \frac{2\pi j}{N}$ and Euler's formula:
$$\sin(\pi x_j) = \frac{1}{2\mathbf{i}} \left( e^{\mathbf{i}\pi x_j} - e^{-\mathbf{i}\pi x_j} \right).$$

Expanding the exponential factors with $e^{\pm \mathbf{i}\pi} = -1$:
$$e^{\mathbf{i}\pi x_j} = e^{-\mathbf{i}\pi} \cdot e^{\mathbf{i}\frac{2\pi j}{N}} = - \left(e^{\mathbf{i}\frac{2\pi}{N}}\right)^j = - q^j,$$
$$e^{-\mathbf{i}\pi x_j} = e^{\mathbf{i}\pi} \cdot e^{-\mathbf{i}\frac{2\pi j}{N}} = - \left(e^{-\mathbf{i}\frac{2\pi}{N}}\right)^j = - (q^{-1})^j,$$
where we set $q := e^{\mathbf{i}\frac{2\pi}{N}}$.

Since $N = 2^i \ge 2$, the ratio $q \neq 1$. Substituting into the trapezoidal sum gives:
$$\sum_{j=0}^{N-1} \sin(\pi x_j) = \frac{1}{2\mathbf{i}} \sum_{j=0}^{N-1} \left( -q^j + q^{-j} \right) = -\frac{1}{2\mathbf{i}} \left( \sum_{j=0}^{N-1} q^j - \sum_{j=0}^{N-1} (q^{-1})^j \right).$$

Applying the geometric sum formula:
$$\sum_{j=0}^{N-1} q^j = \frac{q^N - 1}{q - 1}.$$

Because $q^N = \left(e^{\mathbf{i}\frac{2\pi}{N}}\right)^N = e^{\mathbf{i} 2\pi} = 1$, the numerator is $1 - 1 = 0$:
$$\sum_{j=0}^{N-1} q^j = \frac{0}{q - 1} = 0.$$

Identically, for $q^{-1}$:
$$(q^{-1})^N = e^{-\mathbf{i} 2\pi} = 1 \implies \sum_{j=0}^{N-1} (q^{-1})^j = \frac{1 - 1}{q^{-1} - 1} = 0.$$

---

## 4. Conclusion

Substituting the geometric sums back into $T(h)$:
$$T(h) = -\frac{h}{2\mathbf{i}} (0 - 0) = 0.$$

Therefore:
$$|I - T(h)| = |0 - 0| = 0 \quad \text{for all } N \ge 2.$$

This rigorously proves that the composite trapezoidal rule integrates $f_4(x) = \sin(\pi x)$ on $[-1, 1]$ with **exact error zero** for all $h = (b - a)2^{-i}$, explaining why $f_4$ has zero non-zero errors in Exercise 5.1.
