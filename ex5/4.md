# Problem 5.4: Properties of Newton–Cotes Formulas

---

## (a) Sum of the Weights $\sum_{i=0}^n w_i = 1$

**Hint:** Apply the quadrature formula to a suitable function $f$.

Consider the constant polynomial:
$$f(x) \equiv 1 \in \mathcal{P}_0 \subseteq \mathcal{P}_n.$$

1. **Exact Integral:**
   $$\int_0^1 f(x)\,dx = \int_0^1 1\,dx = 1.$$

2. **Quadrature Formula:**
   By definition of interpolatory quadrature, $\widehat{Q}_n(f) = \sum_{i=0}^n w_i f(x_i)$. Substituting $f(x_i) = 1$:
   $$\widehat{Q}_n(f) = \sum_{i=0}^n w_i \cdot 1 = \sum_{i=0}^n w_i.$$

3. **Exactness:**
   Since $\deg(f) = 0 \le n$, the interpolating polynomial of degree $\le n$ reproduces $f$ identically ($p(x) \equiv 1$). Hence, the quadrature formula is exact for $f$:
   $$\sum_{i=0}^n w_i = \widehat{Q}_n(f) = \int_0^1 1\,dx = 1.$$

*(Alternatively, via the partition of unity of Lagrange polynomials: $\sum_{i=0}^n \ell_i(x) \equiv 1 \implies \sum_{i=0}^n w_i = \int_0^1 \sum_{i=0}^n \ell_i(x)\,dx = \int_0^1 1\,dx = 1$.)*

## (b) Symmetry of the Weights $w_{n-i} = w_i$

**Hint:** Use the symmetry of the points, i.e., $x_j = 1 - x_{n-j}$.

### 1. Verification of Point Symmetry
- **Closed Newton–Cotes:** $x_j = \frac{j}{n} \implies 1 - x_{n-j} = 1 - \frac{n-j}{n} = \frac{j}{n} = x_j$.
- **Open Newton–Cotes:** $x_j = \frac{2j+1}{2n+2} \implies 1 - x_{n-j} = 1 - \frac{2(n-j)+1}{2n+2} = \frac{2j+1}{2n+2} = x_j$.

Thus, for both formulas:
$$x_j = 1 - x_{n-j} \iff 1 - x_j = x_{n-j}.$$

### 2. Proof for the Weights
By definition of the quadrature weights:
$$w_{n-i} = \int_0^1 \ell_{n-i}(x)\,dx = \int_0^1 \prod_{\substack{j=0 \\ j \neq n-i}}^n \frac{x - x_j}{x_{n-i} - x_j}\,dx.$$

Perform the change of variables $y = 1 - x \implies dx = -dy$:
$$w_{n-i} = \int_1^0 \prod_{\substack{j=0 \\ j \neq n-i}}^n \frac{(1 - y) - x_j}{x_{n-i} - x_j}\,(-dy) = \int_0^1 \prod_{\substack{j=0 \\ j \neq n-i}}^n \frac{(1 - x_j) - y}{x_{n-i} - x_j}\,dy.$$

Substitute the symmetry relations $1 - x_j = x_{n-j}$ and $1 - x_{n-i} = x_i$:
- Numerator: $(1 - x_j) - y = x_{n-j} - y = -(y - x_{n-j})$
- Denominator: $x_{n-i} - x_j = (1 - x_i) - (1 - x_{n-j}) = x_{n-j} - x_i = -(x_i - x_{n-j})$

The minus signs cancel:
$$\frac{-(y - x_{n-j})}{-(x_i - x_{n-j})} = \frac{y - x_{n-j}}{x_i - x_{n-j}}.$$

Setting $k = n - j$, as $j$ runs over $\{0, \dots, n\} \setminus \{n-i\}$, the index $k$ runs over $\{0, \dots, n\} \setminus \{i\}$:
$$\prod_{\substack{j=0 \\ j \neq n-i}}^n \frac{y - x_{n-j}}{x_i - x_{n-j}} = \prod_{\substack{k=0 \\ k \neq i}}^n \frac{y - x_k}{x_i - x_k} = \ell_i(y).$$

Therefore:
$$w_{n-i} = \int_0^1 \ell_i(y)\,dy = w_i \quad \text{for all } i = 0, \dots, n.$$

## (c) Exactness for Polynomials of Degree $n + 1$ when $n = 2m$ is Even

Let $n = 2m$ be even, and consider $f(x) = \left(x - \frac{1}{2}\right)^{n+1}$.

### 1. Analytical Integral
Substitute $u = x - \frac{1}{2}$, $dx = du$:
$$\int_0^1 \left(x - \frac{1}{2}\right)^{n+1}\,dx = \int_{-1/2}^{1/2} u^{n+1}\,du.$$
Since $n = 2m$ is even, the exponent $n + 1 = 2m + 1$ is **odd**.  
The integrand $u^{n+1}$ is an odd function integrated over a symmetric interval $[-1/2, 1/2]$:
$$\int_0^1 f(x)\,dx = 0.$$

### 2. Quadrature Evaluation
The quadrature sum is:
$$\widehat{Q}_n(f) = \sum_{i=0}^n w_i \left(x_i - \frac{1}{2}\right)^{n+1}.$$

From point symmetry $x_i = 1 - x_{n-i}$:
$$x_i - \frac{1}{2} = 1 - x_{n-i} - \frac{1}{2} = -\left(x_{n-i} - \frac{1}{2}\right).$$

Since $n + 1$ is odd:
$$f(x_i) = \left(x_i - \frac{1}{2}\right)^{n+1} = \left(-\left(x_{n-i} - \frac{1}{2}\right)\right)^{n+1} = -\left(x_{n-i} - \frac{1}{2}\right)^{n+1} = -f(x_{n-i}).$$

Using weight symmetry $w_{n-i} = w_i$:
- For $i \neq n - i$:
  $$w_i f(x_i) + w_{n-i} f(x_{n-i}) = w_i f(x_i) - w_i f(x_i) = 0.$$
- If $i = n/2 = m$ (the center point in the closed formula):
  $$x_m = \frac{m}{2m} = \frac{1}{2} \implies f(x_m) = \left(\frac{1}{2} - \frac{1}{2}\right)^{n+1} = 0.$$

Summing over all terms:
$$\widehat{Q}_n^{cNC}(f) = 0 \quad \text{and} \quad \widehat{Q}_n^{oNC}(f) = 0.$$

Thus:
$$\int_0^1 f(x)\,dx = 0 = \widehat{Q}_n^{cNC}(f) = \widehat{Q}_n^{oNC}(f).$$

### 3. Conclusion for $\mathcal{P}_{n+1}$
Any polynomial $p \in \mathcal{P}_{n+1}$ can be uniquely written as:
$$p(x) = q(x) + c \left(x - \frac{1}{2}\right)^{n+1}$$
where $q \in \mathcal{P}_n$ and $c \in \mathbb{R}$ is the leading coefficient.

- By definition of interpolatory quadrature on $n+1$ knots, $\widehat{Q}_n$ is exact for all $q \in \mathcal{P}_n$:
  $$\int_0^1 q(x)\,dx = \widehat{Q}_n(q).$$
- By the result above, it is also exact for $\left(x - \frac{1}{2}\right)^{n+1}$:
  $$\int_0^1 \left(x - \frac{1}{2}\right)^{n+1}\,dx = 0 = \widehat{Q}_n\left(\left(x - \frac{1}{2}\right)^{n+1}\right).$$

By linearity:
$$\int_0^1 p(x)\,dx = \int_0^1 q(x)\,dx + c \int_0^1 \left(x - \frac{1}{2}\right)^{n+1}\,dx = \widehat{Q}_n(q) + c\,\widehat{Q}_n\left(\left(x - \frac{1}{2}\right)^{n+1}\right) = \widehat{Q}_n(p).$$

Therefore, for even $n$, the Newton–Cotes formulas $\widehat{Q}_n^{cNC}$ and $\widehat{Q}_n^{oNC}$ are **exact for all polynomials of degree up to $n + 1$**.
